# 画像素材

- `characters/hanamori-sheet.svg`: 花守の横4コマシート。通常、飛行、被弾、ボムの順です。各コマは128×176ピクセル相当です。
- `enemies/`: 通常の狐妖怪と、九尾のボスです。
- `backgrounds/`: 月夜の遠景、中景の神社と山、前景の桜枝を分けています。速度差を付けてCanvas上で縦に繰り返し描きます。
- `bullets/`: 花守の青白い魔法弾と、敵弾の桃・紫・金の3種類です。
- `effects/`: 花びらの爆発、護符の魔法陣、弾の発射光です。

素材の一覧と読み込み状態は `js/assets.js` にまとめています。画像の読み込みに失敗した場合は、ゲーム内のCanvas図形描画へ自動で切り替わります。
